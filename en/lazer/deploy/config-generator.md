# Config Generator

Fill in the `.env` options of
[g0v0-server v1](https://github.com/GooGuTeam/g0v0-server) or the
`config/*.json` options of g0v0 server v2 by hand and generate the matching
configuration files in one click.

Everything is generated locally in your browser — your configuration (including
database passwords, JWT secrets and other sensitive values) is never uploaded
anywhere.

<ConfigGenerator :schema="data" />

## Usage

1. Pick the version you want to generate at the top of the page: "v1 config
   (.env)" or "v2 config (config/\*.json)".
2. Expand the groups and fill in the options. Every option starts from its
   default value, and changed options are highlighted.
   - v1: if you already have a `.env`, click "Import .env", paste it and edit
     the values in the form.
   - v2: only adjust the options you care about and keep the rest as they are.
3. Review the result in the output section at the bottom, then use "Copy",
   "Download .env", "Download" or "Download all (.zip)" to save it.

## Notes

- The `.env` generated by the v1 panel can be placed directly in the root
  directory of your g0v0-server v1 deployment. **Always change the default
  secrets and passwords in production.**
- The `general.json`, `game.json`, `realtime.json`, `chat.json` and
  `storage.json` generated by the v2 panel belong in the `config/` directory of
  every v2 service (e.g. `g0v0.Server.Realtime`). All v2 services should share
  the same `general.json` and `storage.json`.
- When `UseLegacyDatabase` is `true` the v1 MySQL database is used; setting it
  to `false` switches to the PostgreSQL database described by
  `PostgresqlConnectionString`. The form only shows the options of the database
  that is in use (the generated `general.json` keeps both, so you can switch at
  any time).
- `chat.json` is optional: when the file is absent every chat limit falls back
  to the osu-web default.
- See [Configurations](/en/lazer/reference/configurations) for a description of
  every `.env` option, and
  [v2 Configurations](/en/lazer/reference/v2-configurations) for the v2 fields.

## Compared to the config converter

This page is for filling in and generating a configuration **manually**, which
suits fresh deployments or small tweaks. If you already have a complete v1
`.env` and want all the v2 files converted automatically, use the
[Config Converter](/en/lazer/deploy/config-converter) instead.
